A make.fun entry for "Monday, Reviewed in One Line": the funniest
one-line review of my Monday, under 200 characters. `main.py` writes
exactly one line to `/output/entry.txt` — no title, no explanation.

> Monday reviewed itself before I did: one star, would not recommend, already booked again for next week.

## Run

```sh
python3 main.py
```

This prints the line and writes it to `/output/entry.txt`
(or `$OUTPUT_DIR/entry.txt` if that variable is set).
